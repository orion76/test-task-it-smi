# Документация it-smi

Карта проекта для быстрого входа: из чего состоит backend цифровой визитки, как части работают
вместе и что делать при типовой доработке. Здесь только то, что нужно, чтобы начать читать код.

Проект — backend (серверная часть) цифровой визитки: один GraphQL-эндпоинт `/graphql` отдаёт
профиль владельца с навыками, местами работы, проектами и ссылками. Стек зафиксирован заданием:
TypeScript, Node.js, NestJS, Prisma, GraphQL, Docker.

Три источника истины:

- `prisma/schema.prisma` — структура данных: таблицы, колонки, связи;
- `config/api-fields.yml` — что из этой структуры публично и в каком порядке читается;
- `data/profile.yml` — контент визитки, который сидинг переносит в базу.

Устройство определяют два решения. Первое: всё производное выпускают генераторы, поэтому новая
колонка не дублируется в четырёх местах. Второе: слои не знают друг о друге, а соединяет их порт
(интерфейс с одним методом чтения), а не прямой импорт. Оба принципа разобраны в
[`subsystems.md`](subsystems.md), там же — их цена.
