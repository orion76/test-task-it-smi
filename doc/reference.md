# Справочник: источники, каталоги, команды

## Источники истины

| Источник | Что из него выводится |
|---|---|
| `prisma/schema.prisma` | таблицы, колонки, связи, GraphQL-типы, обе JSON Schema |
| `config/api-fields.yml` | публичные запросы, поля, связи, порядок, объявления резолверов |
| `data/profile.yml` | строки базы после сидинга |
| `config/seed.config.yml` | колонка связи и стратегия записи — только то, чего нет в схеме |
| `config/environment.schema.yml` | допустимые переменные окружения и значения по умолчанию |
| `src/schema.gql` | снимок SDL для проверки; файл пишет тест, а не приложение |

## Каталоги

| Путь | Назначение |
|---|---|
| `src/common/` | контракты, порт чтения, конфигурация, общие типы |
| `src/db/` | Prisma-клиент, репозиторий, построение аргументов чтения |
| `src/graphql/` | поведение запросов, загрузчики, регистрация резолверов |
| `src/generated/` | артефакты генерации — руками не править |
| `src/modules/health/` | HTTP и GraphQL проверки живости |
| `prisma/` | схема, миграции, сидинг, генераторы, скрипты пост-обработки |
| `config/` | YAML: контракт API, схемы, конфигурация сидинга |
| `data/` | контент визитки |
| `packages/yaml-loader/` | библиотека чтения и проверки YAML |
| `scripts/` | шаг сборки, который проверяет контракт |
| `docker/` | entrypoint контейнера |
| `client/` | Angular-клиент ручной проверки API |
| `tests/` | юнит- и e2e-проверки |
| `doc/` | документация проекта: карта подсистем, сценарии, справочник |

## Команды

Сборка и проверки:

- `npm run build` — библиотека, генерация, проверка контракта, `nest build`, компиляция сидинга;
- `npm run lint` и `npm run lint:fix` — стиль, форматирование и границы слоёв;
- `npm run typecheck` — пять проектов TypeScript;
- `npm test` — юнит-тесты, включая паритет артефактов и SDL;
- `npm run test:e2e` — e2e на живой PostgreSQL, требует Docker;
- `npm run knip` — неиспользуемые файлы, экспорты и зависимости.

Работа со схемой и данными:

- `npm run prisma:migrate:dev` — создать и применить миграцию локально;
- `npm run prisma:generate` — генерация артефактов и пост-обработка;
- `npm run validate:api-fields` — контракт против сгенерированной схемы;
- `npm run schema:update` — перезаписать `src/schema.gql`;
- `npm run build:seed && npm run prisma:seed` — собрать и прогнать сидинг.

Запуск:

- `docker compose up --build` — база, миграции, сидинг, приложение, клиент;
- `curl -fsS http://localhost:3000/health` — проверка живости;
- `http://localhost:3000/graphql` — Apollo Sandbox и сам эндпоинт.
